API Tester - first start on macOS
=================================

1. Drag "API Tester" onto the Applications folder.

2. Open it from Applications. This build is not notarized by Apple, so macOS
   blocks the first start ("API Tester" Not Opened / cannot be verified).
   Before you allow it, check that the .dmg is the one from the release
   (in the folder with the .dmg and SHA256SUMS.txt from the same release):
       shasum -a 256 -c SHA256SUMS.txt --ignore-missing
   or, with the GitHub CLI:
       gh attestation verify API-Tester-*-mac-*.dmg --repo Manjuhombaradi/api-tester

   Then click "Done" (not "Move to Trash"), and:

   - open System Settings > Privacy & Security,
   - scroll down to the message about "API Tester" and click "Open Anyway",
   - confirm with "Open Anyway" and your password.

   On macOS 14 and older you can also Control-click the app > Open > Open.

   Alternative (Terminal, one command):
       xattr -dr com.apple.quarantine "/Applications/API Tester.app"

macOS asks only once. After that the app starts with a normal double-click.

Command line (CI, scripts) - runs a suite without opening a window:
    "/Applications/API Tester.app/Contents/Resources/bin/api-tester" run my-suite.apisuite
Shorter command:
    sudo ln -sf "/Applications/API Tester.app/Contents/Resources/bin/api-tester" /usr/local/bin/api-tester
    api-tester --help

Security (network use, data on disk, verifying downloads, reporting a vulnerability):
    https://github.com/Manjuhombaradi/api-tester/blob/main/SECURITY.md
